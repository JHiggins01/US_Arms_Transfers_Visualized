# Image sub-Directory
This subdirectory includes the maps generated by both [heatmap.py](heatmap.py) and [typeamtmap.py](typeamtmap.py). 

The maps which follow the naming structure "us_arms_exports_heatmap_{year-year} are heatmaps, titled for the years they represent.

The maps following the structure "us_arms_exports_typemap_{year-year} are the maps that represent weapon types by country, titled for the years they represent.

The other file included is a screenshot of the Tableau landing page, used in the main directory's README file.
